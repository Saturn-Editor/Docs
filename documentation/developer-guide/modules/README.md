# Modules

There are three types of module:

| Type | Manifest | Guide |
| --- | --- | --- |
| Language | `saturn-language.json` | [Languages](languages.md) |
| Extension | `saturn-extension.json` | [Extensions](extensions/README.md) |
| Theme | `theme.json` | [Themes](themes.md) |

When your module is ready, publish it through the [Marketplace](marketplace.md).
