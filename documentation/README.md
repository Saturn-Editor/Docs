# Welcome to Saturn

Saturn is a code editor that you can extend with modules from the [Marketplace](user-guide/marketplace.md):

* **Languages** add support for programming languages, such as code completion, error detection, previews and Run.
* **Extensions** add new features to the editor, such as the Claude Code extension.
* **Themes** change how Saturn looks.

## Get started

* [User Guide](user-guide/README.md): install languages, use the Marketplace and change your settings.
* [Developer Guide](developer-guide/README.md): build Saturn or make your own modules.
