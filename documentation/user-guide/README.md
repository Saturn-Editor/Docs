## Editor features

* **Language features:** use the Outline panel, Find Usages, Rename Symbol, Format Document and parameter hints. These are also in the editor's right-click menu.
* **Debugging:** click the bug button or press F5. To add a breakpoint, click in the column to the left of the line numbers, or press F9. The Breakpoints panel lists them all.
* **Tests:** run tests from the Tests panel or the editor margin.
* **Split editor:** choose Split Right from the tab bar's "…" menu, or press Cmd/Ctrl+\\.
* **Git:** view diffs and blame, stash changes, merge and delete branches, rebase interactively, resolve conflicts in the merge editor, and manage remotes.
* **Updates:** Saturn updates itself, and tells you when your installed modules have updates.
