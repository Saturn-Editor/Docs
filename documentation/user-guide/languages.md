# Languages

When you first install Saturn, you'll be asked which Language modules you'd like to add. This adds support for those language servers in the editor.

You can manage your installed modules, and install more at the [Saturn Marketplace](marketplace.md).

## Choosing a language for a file

The language name in the status bar shows which language a file uses. Click it to choose a different language for that file, or for every file with that extension when more than one language supports it.

To change a project's language, right-click the project in the Welcome window and choose **Change language…**.

## Other marketplaces

You may be able to add additional languages from community marketplaces. However, we recommend only using the Saturn Marketplace since these modules are all reviewed by Saturn's maintainers.
