# Settings

Settings has six sections: Appearance, Editor, Languages, Keymap, Marketplace and Advanced. Settings for your installed extensions are listed after these, below a divider.

## Appearance

* **Theme:** choose a theme. Install more themes from the [Marketplace](marketplace.md).
* **Light / Dark:** choose light or dark mode, or turn on **Sync with OS**.
* **Text size:** 80%, 90%, 100%, 110%, 125% or 150%. This changes the text size in every Saturn window.

## Editor

### Behaviour

* **Indentation:** spaces or tabs, with a size of 2, 4 or 8.
* **Auto-indent**
* **Auto-close** brackets and quotes: `(` `[` `{` `<` `'` `"`
* **Format on save**
* **Auto-save:** while typing, when you stop typing or close a file, or off.
* **Encoding:** UTF-8, UTF-16, US-ASCII or ISO-8859-1.

### SmartCode

Turn code completion and error detection on or off.

## Languages

Each installed [language](languages.md) has its own tab, with:

* the language's settings
* the default view for each file type that has a preview
* switches for each language feature, or "Not supported" if the language doesn't provide it

## Keymap

Choose the keyboard shortcuts for your operating system, or for IntelliJ, Visual Studio or VS Code. To make your own keymap, duplicate one and record new shortcuts.

## Marketplace

The URL of the Marketplace index.

## Advanced

* Automatically check for updates to Saturn and your installed modules.
* **Check for updates:** check now.
* **Reset Saturn**
